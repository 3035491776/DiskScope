# DiskScope v0.2.0 朋友测试清单 v3

请按自己的理解使用测试包，不需要先阅读技术文档。不要选择仍然需要的真实文件；如需验证处理流程，请自行准备可丢弃的测试文件。

1. 你能不能快速找到最占空间的大文件？
2. 你能不能快速找到半年或一年没有修改的文件？
3. 文件类型分类是否够用？
4. 有没有你常见的文件类型被分到“其他文件”？
5. 位置、类别、扩展名、大小、时间和搜索筛选是否容易理解？
6. 你是否能把几千个文件快速缩小到几十个？
7. “选择当前筛选结果”是否自然？超过 200 个时的提示是否清楚？
8. 你是否理解“很久未修改”不等于“肯定没用”？
9. 你是否理解“可处理 / 建议手动检查 / 不建议处理”的区别？
10. 你是否理解危险程序类型即使能搜索到，也不能勾选处理？
11. 清理过程中是否仍然觉得要点太多次？
12. 你还需要什么筛选？
13. 你是否理解文件进入了 Windows 回收站，而不是被永久删除？
14. 你是否理解进入回收站不等于已经释放相同容量？

请同时记录 Windows 版本、屏幕分辨率、测试的扫描范围，以及是否出现文字截断、横向滚动、焦点丢失或无法关闭的确认框。
