# DiskScope v0.1.1 朋友测试清单

请不要提前阅读项目文档，也不需要了解 DiskScope 的内部术语。按自己的理解使用测试包，然后回答：

1. 第一次打开时，你知道应该点哪里吗？
2. 你知道“扫描 C 盘”会不会删除文件吗？
3. 扫描过程中，你看得懂它正在做什么吗？
4. 扫描结束后，你能找到最占空间的文件夹吗？
5. 你能找到大文件吗？
6. “空间建议”你看得懂吗？
7. 你知道为什么有些文件不能处理吗？
8. 你有没有看到不理解的英文或术语？
9. 有没有哪个按钮让你不知道它会做什么？
10. 如果只能改一个地方，你最想改什么？

请同时记录 Windows 版本、屏幕分辨率，以及是否出现文字被截断或横向滚动。
