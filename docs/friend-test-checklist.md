# DiskScope v0.2.0 第二轮朋友测试清单

请按自己的理解使用测试包，不需要先阅读技术文档。不要选择仍然需要的真实文件；如需验证处理流程，请自行准备可丢弃的测试文件。

1. 扫描完以后，你知道下一步可以做什么吗？
2. 你能找到“清理空间”吗？
3. 你理解“可处理 / 建议手动检查 / 不建议处理”的区别吗？
4. 你敢处理“可处理”的文件吗？为什么？
5. “建议手动检查”的提醒和额外确认够不够？
6. 你是否误以为“不建议处理”也能强制删除？
7. “可处理”的批量选择是否自然？
8. “建议手动检查”必须逐项选择是否合理？
9. 成功、跳过和失败的处理结果是否看得懂？
10. 你是否理解文件进入了 Windows 回收站，而不是被永久删除？
11. 你是否理解进入回收站不等于已经释放相同容量？
12. 还有没有“只能看不能做”的感觉？

请同时记录 Windows 版本、屏幕分辨率、测试的扫描范围，以及是否出现文字截断、横向滚动、焦点丢失或无法关闭的确认框。
