# M2 空间分析界面

总览中的扫描大小、文件数、目录数和耗时来自当前扫描状态 API；本机磁盘容量来自 Windows 固定卷容量接口。这两组数字含义不同，容量卡片不能发起整卷扫描。所有扫描创建请求仍由既有根目录白名单和 `WHOLE_VOLUME_SCAN_NOT_APPROVED` 安全门审核。

空间分析只请求当前层级的 `GET /api/v1/scans/{id}/directories?parent_id=...`。图表最多显示 20 个子目录，其余合并为“其他”；相邻表格保留当前层级的数字和下钻入口。大文件使用既有 Top-K，Top 大目录由已聚合的目录元数据按 `subtree_bytes` 排序，不重新读取目标文件。扫描结果只驻留进程内存，不建立快照或历史数据库。

目录的“覆盖受限”只标记跳过或错误所在目录的祖先；任务整体有跳过或错误时，总体显示“扫描完成，覆盖受限”。取消任务的结果始终视为不完整。空值和无法获取的容量、时间或资源指标显示“—”，不补零或估算。页面默认显示友好范围名和相对路径；仅在用户主动复制路径时组装完整路径。

`GET /api/v1/volumes` 只枚举 Windows `DRIVE_FIXED` 卷并读取容量字节数，排除网络盘和可移动盘。接口需要本机会话，不接受路径参数，也不访问卷内文件。`scan_allowed` 始终为 `false`。

前端使用 Vue Router、Pinia 和 ECharts；分析页按需加载图表。保留单扫描任务、metadata-only、reparse 不跟随、不跨卷和协作式取消。M2 不包含清理、删除、移动、任意目录选择或 C:\ 整卷扫描。
