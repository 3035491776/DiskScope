# DiskScope v0.1.1 朋友测试版快速开始

DiskScope 是面向 Windows 的安全、低影响磁盘空间诊断工具。

## 系统要求

- Windows 10 或 Windows 11，64 位 x64。
- 普通用户权限；不需要管理员权限。
- 系统默认浏览器。

## 开始使用

1. 将 `DiskScope-v0.1.1-test-windows-x64.zip` 完整解压；不要直接在 ZIP 内运行程序。
2. 双击 `DiskScope.exe`。
3. 在打开的页面中选择“Windows C 盘”或“临时文件”。
4. 点击“扫描 C 盘”或“扫描临时文件”。

不需要安装 Python、Node.js、npm 或其他开发工具。如果浏览器未自动打开，请按启动窗口提示手动打开本地地址。

## 安全说明

- 扫描只读取文件和文件夹的大小、时间等基本信息，不读取文件正文。
- DiskScope 不需要管理员权限，不会跟随系统链接或进入另一块磁盘。
- 只有极少数符合全部安全条件的单个临时文件才会出现处理按钮，而且只能移入 Windows 回收站。

## 数据与日志

- 数据库：`data\diskscope.db`
- 日志：`logs\launcher.log`、`logs\backend.log`

升级时请保留 `data` 目录。不要把新版本直接覆盖到不可写的系统目录。

## 退出与故障

关闭启动窗口或按 Ctrl+C 会停止本地服务。端口 8765 已被占用时，DiskScope 会安全退出，不会终止其他进程。

此 v0.1.1 朋友测试版未进行代码签名。Windows SmartScreen 或安全软件可能显示未知发布者/声誉提示；请向提供测试包的人核对 ZIP 的 SHA-256，不要关闭或绕过系统安全功能。
