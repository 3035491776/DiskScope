# DiskScope v0.2.0 朋友测试版快速开始

DiskScope 是面向 Windows 的安全、低影响磁盘空间诊断工具。它帮助你找到占用空间的文件，并按安全等级决定下一步。

## 系统要求

- Windows 10 或 Windows 11，64 位 x64。
- 普通用户权限；不需要管理员权限。
- 系统默认浏览器。

## 开始使用

1. 将 `DiskScope-v0.2.0-test-windows-x64.zip` 完整解压；不要直接在 ZIP 内运行程序。
2. 双击 `DiskScope.exe`。
3. 扫描“Windows C 盘”或“临时文件”。
4. 查看空间占用和大文件。
5. 进入“清理空间”。
6. 根据“可处理 / 建议手动检查 / 不建议处理”决定是否处理。

不需要安装 Python、Node.js、npm 或其他开发工具。如果浏览器未自动打开，请按启动窗口提示手动打开本地地址。

## 安全说明

- 扫描只读取文件和文件夹的大小、时间等基本信息，不读取文件正文。
- DiskScope 不需要管理员权限，不会跟随系统链接或进入另一块磁盘。
- “可处理”只来自现有严格临时文件策略；“建议手动检查”仅限当前用户的普通文件夹，并要求逐项选择和额外确认。
- “不建议处理”没有复选框，也不能强制处理。
- 所有处理操作都只会把普通文件顺序移入 Windows 回收站；不会永久删除、删除文件夹或自动清空回收站。
- 文件进入回收站后仍可能占用磁盘空间，直到你通过 Windows 自行确认并清空回收站。

## 数据与日志

- 数据库：`data\diskscope.db`
- 日志：`logs\launcher.log`、`logs\backend.log`

升级时请保留 `data` 目录。不要把新版本直接覆盖到不可写的系统目录。

## 退出与故障

关闭启动窗口或按 Ctrl+C 会停止本地服务。端口 8765 已被占用时，DiskScope 会安全退出，不会终止其他进程。

此 v0.2.0 朋友测试版未进行代码签名。Windows SmartScreen 或安全软件可能显示未知发布者/声誉提示；请向提供测试包的人核对 ZIP 的 SHA-256，不要关闭或绕过系统安全功能。
